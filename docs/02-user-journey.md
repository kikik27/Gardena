# 02 — User Journey

## Persona
- Beginner DeFi user
- Wants yield, fears hidden risk
- Needs simple controls and emergency stop

## End-to-End Flow
1. Connect wallet
2. Pick crop strategy
3. Set risk policy
4. Review AI plan
5. Execute transaction
6. View diary and outcomes
7. Pause anytime

## Core Screens
- Landing / Garden selection
- Policy settings
- Agent diary
- Benchmark dashboard
