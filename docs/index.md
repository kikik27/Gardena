# Mantle Garden Docs

## What
Beginner-first DeFi app. User pick crop strategy. AI execute with guardrails.

## Flow
1. User pick crop + amount
2. Agent plan strategy
3. Policy check block/allow
4. Execute tx on Mantle
5. Log decision + outcome
