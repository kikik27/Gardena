# 01 — Vision & Product

## Vision
Build trusted AI companion for DeFi beginners.

## Product Summary
Gardena turns DeFi strategies into farm metaphors:
- Rice: low risk, stable yield
- Corn: medium risk, balanced return
- Chili: high risk, high return

User selects crop and amount.
Agent plans and validates action under policy bounds.
System logs decision hash and outcome.

## Success Metrics
- Time-to-first-action
- Policy-block correctness
- Decision transparency score
- Return stability per risk tier
